🏋️ SALLEGYM – Logiciel de gestion de salle de sport
SALLEGYM est une application de bureau développée en Python, conçue pour faciliter la gestion quotidienne d'une salle de sport. Elle propose une interface graphique intuitive permettant de gérer les abonnements des membres, suivre les paiements, enregistrer les ventes et contrôler les dates d'expiration.

🚀 Fonctionnalités principales
Gestion des membres : Ajouter, modifier, supprimer et consulter les informations des adhérents.
Gestion des abonnements : Enregistrer les dates de début et de fin des abonnements.
Suivi des expirations : Identifier automatiquement les membres dont l'abonnement est arrivé à expiration.
Gestion des paiements : Enregistrer les paiements et calculer le montant total encaissé.
Gestion des produits : Ajouter, modifier et supprimer des produits, avec suivi des quantités et des prix.
Gestion des ventes : Enregistrer les ventes, calculer les bénéfices et consulter l'historique.
Gestion des photos : Associer une photo à chaque membre pour faciliter son identification.
Stockage des données : Utilisation de fichiers JSON pour sauvegarder les informations.
🛠️ Technologies utilisées
Python
Tkinter
CustomTkinter
JSON
Pillow (PIL)
TkCalendar
QRCode
🎯 Objectif du projet
L'objectif de SALLEGYM est de proposer une solution simple et pratique pour automatiser les tâches administratives d'une salle de sport, améliorer le suivi des adhérents et faciliter la gestion financière et commerciale.
